A small personal tool that prepares short educational videos and sends them to the creator's own TikTok drafts for review.

What it does

The tool writes scripts, renders each one into a video, and then uploads the finished video to the draft inbox of one TikTok account: the account owned by the person who runs the tool. The owner then opens TikTok, reviews the video, adds the caption, and decides whether to post it.

How it uses TikTok

The tool signs in with TikTok Login Kit, with the owner's permission, and uses the Content Posting API upload feature. It does not post on its own, read other people's data, or serve any other users.
